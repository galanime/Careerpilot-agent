# AI Agent Engineer Intern 示例 JD

## 岗位职责

- 负责 AI Agent 应用平台的后端开发和工作流编排能力建设。
- 设计并实现 Tool Calling、任务拆解、执行状态追踪和异常处理机制。
- 结合 RAG、向量检索和结构化知识库提升 Agent 输出的准确性和可解释性。
- 建设 Agent 评测流程，跟踪关键词覆盖、幻觉风险、任务成功率和执行耗时。

## 任职要求

- 熟悉 Go 或 Python，具备扎实的后端工程能力。
- 理解 LLM、Prompt Engineering、RAG、Function Calling 或 Tool Calling。
- 熟悉 HTTP API、数据库、缓存、异步任务和基础系统设计。
- 有 AI Agent、LLM 应用、自动化工作流或评测平台项目经验优先。

## 加分项

- 熟悉 React / TypeScript，能完成 Agent Trace 或可观测页面。
- 有 OpenTelemetry、SSE、Docker、PostgreSQL、Redis 或向量数据库经验。
- 有真实项目落地意识，能区分 Demo、测试、生产和安全边界。
